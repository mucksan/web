🔴 本書の大原則

  1. RTW本券とは別券。遅延しても RTW 側は救済されない。乗継は自分で厚く取る。
  2. 11/2 のマチュピチュ入場券は購入済み・日時固定・再発行不可。
    → C2 の遅延は旅程全体で最も損害が大きい。ここだけは価格で選ばない。
  3. C6 は「安い運賃」ではなく「変更できる運賃」を買う区間。

C2. LIM → CUZ（11/1）🔴 最優先

制約の変化: ✅ A-1 成立で 10/31 22:45 リマ着となり、11/1 は普通の朝を迎えられる。
🔴 さらに 手配_鉄道.md の調査で、オリャンタイタンボ〜マチュピチュ村の鉄道が
2026年に2度（2025/12 の列車衝突、2026/8 の線路火災）運行停止していることが判明した。
✅ 2026/9/9 時点で全便の販売が確認できており段階的再開は完了しているが、路線が脆いこと自体は変わらない。
→ 朝便は「選べる」ではなく「取るべき」。後続列車を保険として複数残せるため。

✅ 接続する列車は D1＝Vistadome Observatory 303（13:27発・14:50着）に確定した。
着後 → 送迎1h45m → オリャンタイタンボ → 13:27 の列車の連鎖で逆算する。
PeruRail の推奨集合は発車30分前（＝12:57 までにオリャンタイタンボ駅）。

🔴 C2 補足：11/1 は「オリャンタイタンボ駅で荷物を預ける」工程が入る

PeruRail は車内持ち込みを 8kg・三辺合計115cm に制限しており、
世界一周のスーツケースは列車に乗らない。
オリャンタイタンボ駅の荷物預かり（04:15〜21:00）に預け、11/3 の復路到着時に回収する。
→ CUZ 着から列車発車までに、送迎1h45m ＋ 荷物預け ＋ 荷物の詰め替えが入る。
詳細は 手配_鉄道.md §5。D3 の送迎手配にこの立ち寄りを条件として含めること。

🔴 なぜ価格で選ばないか

  • クスコ空港（CUZ）は午後に風の影響で遅延・欠航が出やすい。午前着が原則。
  • 11/2 の入場券は購入済み・日時固定・再発行不可（tickets/マチュピチュ/費用明細.md）。
    11/1 に村へ着けなければ S/369.32 と旅程の中心が同時に消える。
  • LATAM は LIM–CUZ の便数が最多で、欠航時に当日中の後続便へ振り替えられる可能性が最も高い。
    JetSMART／Sky との差額 $10〜30 は、この保険料として払う価値がある。

✅ 推奨：LA2013（07:40）を本命、LA2130（08:05）を保険として同日に把握しておく。

再取得の方法

本書の便名・時刻・運賃は tools/flightwatch の search() で取得した。更新する場合:

cd tools/flightwatch
python -c "
import sys; sys.path.insert(0,'.')
from flightwatch import search
for it in search('LIM','CUZ','2026-11-01',seat='economy',max_stops=0):
    print(it.price, [(l.flight,l.dep,l.arr) for l in it.legs])
"

⚠️ Google Flights の運賃は目安。実際の購入可否・運賃クラス（EcoFly 等）・
受託手荷物条件は各社公式サイトで確認すること（tools/flightwatch/README.md の限界の項を参照）。
