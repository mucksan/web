🔴 価格設定に一貫性がない

同じ車両クラスでも便によって $58.90〜$175.75 と3倍の開きがある。
「Vistadome だから高い」ではなく、便ごとに個別に見ないと損をする。

例
往路 12:55 73P Expedition と Vistadome が同額 $65.55
往路 08:29 33 V. Observatory が $175.75（同じ Observatory でも 13:27 の 303 は $94.05）
復路 13:37 204 Expedition $75.05 が、12:46 の Vistadome $65.55 より高い（＝完全に負けている）

接続: C2（LIM→CUZ ＝ LA2013 07:40→09:05）→ 専用送迎 約1h45m（D3）→ オリャンタイタンボ 11:00頃。

内容
便 Vistadome Observatory 303
発着 13:27 → 14:50（1h23m・全便中で最速）
価格 $94.05（定価 $99）
接続余裕 オリャンタ11:00着に対し 2時間27分（PeruRail の推奨集合は発車30分前＝12:57）

採用理由

✅ バーカー・軽食/ドリンク込み・ライブ演奏・伝統舞踊
✅ オリャンタイタンボ駅の待合ラウンジが使える 復路（D2）到着後、D4 の送迎待ちにも効く
✅ 全便中で最速の1h23m 村着 14:50 で明るいうちに投宿でき、翌日07:00のワイナピチュに備えられる
✅ "P" が付かない便 §4 の懸念を回避できる

⚠️ ベビーアルパカのファッションショーは付かない。販売画面の注記(1)により
「マチュピチュ村発の便のみ」＝復路限定。
オープンバルコニー・バーカー・ライブ演奏・伝統舞踊は往路にも付く。

接続: オリャンタイタンボ 14:19着 → 荷物回収（§5）→ 陸路でクスコへ（D4・約1h45m）→ クスコ 16:00頃着。

価格 $65.55（定価 $69）

採用理由
✅ 往路（Observatory 303）で同じ渓谷を最上位車両で見た直後 復路は同一区間の逆走。車窓の限界効用が落ちており、ここに $67.45 を追加する意味が薄い
✅ 11/3 はクスコ（3,400m）へ上がる日 12:46 発なら クスコ 16:00頃着。13:37 発だと 16:45頃。高山病回避の設計上、初日は早く着いて静かに過ごす
✅ 午前中に村を散策できる 温泉・博物館。08:53 発だと朝の余裕が消える
✅ 13:37 の Expedition より安い $65.55 < $75.05。上位車両なのに安い
✅ "P" が付かない便 §4 の懸念を回避できる

🔴 「13:37 Observatory 204（$133.00）」を採らない理由

差額 $67.45（約¥10,450）に対して得られるのは：

  • オープンバルコニー → ✅ 往路の 303 で体験済みになる
  • バーカー・ライブ演奏 → ✅ 同上
  • ベビーアルパカのファッションショー → 🔴 これだけが復路固有

さらに 45分遅くなり、標高を上げる日の余裕を削る。加えて往復 $198.55 で予算枠 $190 を超える。

5. 🔴 手荷物 8kg・115cm 制限 — 大型スーツケースは乗らない

販売画面の車両説明に明記されている条件：

Hand Luggage Allowance: up to 8 kg and 115 cm (total linear dimensions)

🔴 PeruRail は車内持ち込みを 8kg・三辺合計115cm に制限している。世界一周のスーツケースは持ち込めない。

解決策：オリャンタイタンボ駅の荷物預かり

販売画面の注記(3)より：

場所 営業時間
オリャンタイタンボ駅（Av. Ferrocarril s/n） 04:15 〜 21:00
マチュピチュ村駅（Av. Machu Picchu Pueblo s/n, Las Orquídeas） 05:00 〜 22:00

✅ 運用案

日付 行動
11/1 クスコ空港 → 送迎（D3）→ オリャンタイタンボ駅着 11:00頃
→ 🔴 大型スーツケースを駅の預かりへ（営業時間内・余裕あり）
→ 13:27 の列車には小型バッグのみで乗車
11/1〜2 マチュピチュ村2泊。小型バッグで足りる構成にする
11/3 14:19 オリャンタイタンボ着 → スーツケース回収（営業時間内）
→ D4 の送迎でクスコへ

✅ 往路13:27発・復路14:19着とも、駅の営業時間 04:15〜21:00 に余裕で収まる。
✅ Observatory（D1）を選んだので、オリャンタイタンボ駅の待合ラウンジも使える。

⚠️ パッキングへの影響。11/1 朝にクスコ空港で荷物を受け取ったあと、
車内で 2泊分を小型バッグへ移し替えるか、あらかじめ分けて詰めておく必要がある。
送迎車（D3・約1h45m）の中で作業できるよう、分割しやすい詰め方にしておくこと。
🔴 11/2 のマチュピチュ入場にはパスポート原本が必要（券が氏名・パスポート紐付け）。小型バッグ側へ。

🔴 参考：便名の "P" について

往路で "P" が付くのは 73P・83P、復路は 72P・74P・84P・86P のみ。
PeruRail は一部ダイヤで Pachar 駅を乗換点とするバイモーダル（バス＋列車）を運用しており、
P はそれを指す可能性がある（＝実際の乗車駅がオリャンタイタンボでない恐れ）。

✅ 今回選定した 303（往路）と 602（復路）はどちらも "P" が付かないため、この懸念は回避できている。
⚠️ ただし保険列車として 73P・74P・84P 等へ振り替える場合は、
販売画面の「ⓘ Train」リンクで実際の乗車駅を必ず確認すること。
