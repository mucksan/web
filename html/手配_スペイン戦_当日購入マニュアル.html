4. 当日の画面遷移と注意点

Step 1. 待機列（Queue-it）が発生した場合

アクセス集中時、画面に「Virtual Waiting Room（仮想待機室）」が表示される場合があります。
* 絶対にページをリロード（F5）しないでください！（順番が最後尾に回されます）
* 自動的に画面が切り替わるまで待機します。

Step 2. Cloudflareの認証が出た場合

「Verify you are human（人間であることを確認します）」のチェックボックスが出た場合は、落ち着いてクリックして通過します。

Step 3. 3Dセキュア（本人認証）の突破

クレジットカード番号を入力後、カード会社の認証画面に遷移します。
* 手元のスマートフォンにSMS等でワンタイムパスワード（OTP）が届くか、銀行・カード会社アプリに承認通知が届きます。
* 認証の有効期限は通常2〜3分以内のため、手元スマホをすぐ手にとれる状態にしておくことが最重要です。

Step 4. 完了画面と確認メール

  • 決済が完了すると 「Código de reserva（予約番号）」 が表示されます。念のため画面全体のスクリーンショットを撮っておきます。
  • 登録メールアドレスに以下の2通のメールが届きます：
  • チケット購入完了の領収控え
  • RFEF Tickets アプリ への紐付け案内（仮パスワードなど）
    ※迷惑メールフォルダに振り分けられることがあるため、必ず確認してください。

5. 自動化の検討と「ワンクリック半自動入力（ブックマークレット）」

5.1 なぜ「完全自動ボット」は危険なのか？

PlaywrightやPython等による完全自動化スクリプトは技術的に作成可能ですが、チケット争奪戦においては極めてリスクが高く非推奨です。

リスク要因 内容・致命的な影響
🔴 Cloudflare WAF による即時BAN tickets.rfef.es の前面には Cloudflare が設置されています。自動化ライブラリ特有のブラウザ識別子（navigator.webdriver 等）により高確率でボット判定を受け、CAPTCHA地獄で停止するか、東京クラウドPCのIPアドレスごとアクセス遮断 されます（手動でも買えなくなります）。
🔴 3Dセキュア（2段階認証）の壁 最終決済時のSMSワンタイムパスワード（OTP）や銀行アプリ承認は、セキュリティ上完全自動化できません。
🔴 規約違反・チケット取消リスク ボット購入は利用規約で厳格に禁止されており、検知された場合は購入後であってもチケット強制無効化・返金なしのリスクがあります。

5.2 推奨アプローチ：ワンクリック自動入力（ブックマークレット）

最も安全かつ確実に最速購入できるのは、「本物のブラウザ（人間）としてアクセスし、個人情報入力だけを0.1秒で自動完結させる」 半自動化です。

    A["人間がブラウザで操作<br>（Cloudflareを100%無効化）"] --> B["19:00 ゾーン・枚数選択"]
    B --> C["フォーム画面で<br>ブックマークレットを1クリック！"]
    C --> D["全項目（氏名・旅券・連絡先）が<br>0.1秒で一括自動入力！"]
    D --> E["決済・3Dセキュアへ進む"]

    style A fill:#3498db,stroke:#2980b9,color:#fff
    style C fill:#f39c12,stroke:#d35400,color:#fff
    style D fill:#2ecc71,stroke:#27ae60,color:#fff
  • Cloudflare検知リスクゼロ: 通常のChrome/Edgeブラウザを手動で操作するため、ボット判定を一切受けません。
  • 圧倒的な時短: 手作業でのコピペ（30〜60秒ロス）を 「わずか1秒」 に短縮し、ライバルに大差をつけられます。

ブックマークレットのコード雛形（例）

ブラウザのブックマークバーに「チケット自動入力」として以下のJavaScriptを登録します：

javascript:(function(){
  // フォーム各項目を0.1秒で自動入力
  const inputs = {
    name: 'TAKESHI',
    surname: 'TAKAMUKU',
    dni: '【パスポート番号】',
    email: '【メールアドレス】',
    phone: '【電話番号】'
  };
  for (const [key, val] of Object.entries(inputs)) {
    const el = document.querySelector(`input[name*="${key}" i], input[id*="${key}" i]`);
    if (el) { el.value = val; el.dispatchEvent(new Event('input', {bubbles: true})); }
  }
})();
