2. 🔴 欠航率 30〜40% — これが本テーマの核心

事実

項目 内容
🔴 欠航率 全フライトの約 30〜40% が悪天候で中止（通年平均）
運航は1日1回のみ 日の出時のみ。1日あたり最大約160機
中止条件 雨・霧・雪・風速 約7mph（約3m/s）超
判断のタイミング 🔴 当日早朝、トルコ側の気球当局が判断。
ホテルでピックアップされた後に中止が告げられることもある
11月の位置づけ 運航好適期（4〜11月）の末端。冬型が入り始める

現行行程の脆弱性

11/21 夜  カッパドキア着
11/22 朝  ★気球（唯一のチャンス）  ← ここで欠航したら終わり
11/23 朝  NAV → IST（移動）

🔴 チャンスが1回しかないため、確率的には 30〜40% の割合で「気球に乗れないまま去る」ことになります。
これは本旅程で最も高い「体験を落とす確率」です。

3. 🔴 対策：11/23 朝を予備日に変える

NAV ⇄ IST の便数を調べたところ、予備日を作る余地があります。

項目 実態
運航会社 Turkish Airlines（週47便）＋ AJet（週17便）
1日あたり 平均5便
運航時間帯 02:05 〜 20:45（IST→NAV の幅）
所要 約1時間20分

つまり NAV→IST は午後便が確保できます。

気球のタイムライン（11/23 に再挑戦する場合）

時刻 行動
04:30 ホテルピックアップ
05:30-06:00 離陸（日の出）
06:30-07:15 着陸（飛行時間 50〜75分）＋シャンパン・トースト
08:00-08:30 ホテル帰着
09:30 チェックアウト → NAV 空港へ（約45分）
12:00-14:00 NAV → IST 午後便
15:00-16:00 イスタンブール着

11/23 朝に飛んでも、当日中にイスタンブール入りできます。

🔴 推奨する手当て

NAV → IST の航空券を「変更可能な運賃」で 11/23 午前便として押さえる。
- 11/22 に飛べた → そのまま午前便に乗り、予定どおりイスタンブール観光
- 11/22 が欠航 → 🔴 午後便へ変更し、11/23 朝に再挑戦

代償：11/23 の午後便に変えた場合、アヤソフィア／ブルーモスクの時間が消えます。
その分は 11/24 午前（グランドバザール・ボスポラスクルーズ枠）から捻出することになります。
🔴 ただし 11/24 は 18:45 の観戦が絶対条件なので、詰め込みすぎないこと。

成立します。ただし
- 🔴 TK1840 が遅延すると国内線に乗り継げない（別手配なので保護されない）
- 🔴 同一予約でないため、遅延時の振替は自己負担

対策：IST→NAV は 18:00〜19:00 発を選べば乗継余裕が3時間半以上になります。
ホテル着は 21:00 頃になりますが、乗り遅れて初日を失うリスクのほうが重いと考えます。

5. 手配方法の比較（Klook / 運航会社直販 / 比較サイト / 日本語）

5.1 🔴 まず知っておくこと：直販が 15〜25% 安い

運航会社に直接（サイトまたはメールで）予約すると、OTA 経由より 15〜25% 安い。

本件は「欠航リスクが最大の論点」なので、価格差より振替条件を優先すべきです。

6. タイムチャート変更の選択肢

変更案①（推奨）：日程は変えず、航空券で予備日を買う

NAV→IST を変更可能運賃にするだけ。日程表の変更は不要で、
欠航時にだけ 11/23 午後便へ振り替える。差額は変更手数料のみ。

  • ✅ 費用が最小。日程への影響もゼロ（飛べた場合）
  • ❌ 欠航時はイスタンブール観光が半日削られる

変更案②：カッパドキアを1泊延ばす（11/23 もカッパドキア泊）

11/23  カッパドキア泊（気球チャンス2回目 = 11/23朝）
11/24  朝 NAV → IST（気球チャンス3回目 = 11/24朝も理論上は可）
       → 18:45 観戦
  • ✅ 気球チャンスが2〜3回に増え、搭乗確率が 60% → 85%以上に上がる
  • ❌ 🔴 イスタンブール観光がほぼ消える（アヤソフィア・ブルーモスク・バザール全て）
  • ❌ 🔴 観戦当日の朝に飛行機移動。遅延したら絶対条件を落とす
  • → リスクの質が悪い。推奨しません

変更案③：ギョレメ以外の谷（Soganli Valley）を選ぶ

ギョレメ上空が風で閉じても、南のソアンル渓谷は飛べる日があるとされます。
確実な保証ではありませんが、11/22 に賭ける場合の当たり判定を少し広げられます。

  • 予約時に「ギョレメが欠航でも別谷で飛ぶか」を運航会社に確認する価値あり

変更案④：気球を諦める前提で組む — ❌ 非推奨

カッパドキアは気球が主目的です。日程を組み替えてでも搭乗確率を上げる価値があります。
