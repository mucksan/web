✅ RTW区間は原則ビジネスでカバーされる

RTW 16クーポンのうち 飛行15区間、予約クラスは ANA系＝Z／他社＝D。
🔴 例外は UA1271（10/29 SFO→MEX）のみで、予約クラス B＝エコノミー。
→ S-1 のウォッチ対象（TODO A6・期限 10/28）。S-1 が成立すれば United Club が使えて §2-③ の穴も消える。

2. 🔴 3つの穴

① IST（11/21）— 最も痛い

IST→NAV は国内線。Priority Pass の IGA Lounge は国際線専用。
TK1840 が 14:30 着で TK2008 が 19:40 発なので、5時間10分がラウンジなしになる恐れ。

確認すべき代替:

# 案
1 🔴 Turkish Airlines の到着ラウンジ（Arrival Lounge）。TK1840 をビジネス（D）で降りるので、対象になるか確認する価値がある
2 iGA Domestic Lounge（140席・国内線出発フロア）が Priority Pass 対象か確認
3 IGA Pass の当日券（walk-in・2026年時点で €100前後）。高いので最後の手段

② CUZ（11/5 05:00発）

Hanaq VIP Lounge は PP 対象だが、05:00 発だと開館前の可能性がある。
Priority Pass は出発3時間前から入場可という運用だが、ラウンジ自体が開いていなければ意味がない。
→ 開館時刻を Priority Pass アプリまたはラウンジに確認する。

③ SFO（10/29）

PP のラウンジは International Terminal A のコンコース限定。
UA1271 の出発コンコースと一致するか要確認（SFO の International Terminal は A と G で保安検査が分かれており、片方から他方へは行けない）。

✅ ただし S-1（UA1271 のビジネス化）が成立すれば United Club が使えるので、この穴は S-1 次第。
なお 10/28 は NH8 で 10:20 SFO 着（到着のみ）。ラウンジが要るのは 10/29 の出発（10:45）で、滞在は1時間程度なので優先度は低い。

3. ⚠️ 最大滞在時間の制限に注意

ラウンジ 上限
GRU T1 W Lounge 3時間
IST IGA Lounge（PP利用時） 3時間
GRU T2 Advantage VIP Lounge ✅ 24/7・時間制限なしとの記載

🔴 GRU の6時間10分は、3時間上限のラウンジ1軒では足りない。
→ 時間制限のない店（Advantage VIP 等）を選ぶか、2軒をはしごする。
T2 には24時間営業が複数あるので、現地で選択肢はある。
